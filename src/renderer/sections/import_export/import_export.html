Format du fichier Excel

Le format dépend du niveau de la classe :

Format UA — Niveaux 1 & 2 (SIL, CP, CE1, CE2)
Fichier nommé : ELIMU_CE1-A_2025-2026.xlsx
Ligne 1 : En-tête (ignorée). Une ligne par (élève × sous-compétence × UA).
Col A : Nom et Prénom
Col B : Sous-Comp. (ex: 1A, 2B, 4, 6A1)
Col C : UA (UA1 à UA8)
Col D : Orale (note sur le max MINEDUB, ex: sur 20, 12, 8…)
Col E : Écrite (note sur le max MINEDUB, ex: sur 15, 28…)
Col F : Pratique (note sur le max MINEDUB)
Col G : Savoir-être (note sur le max MINEDUB)
💡 Un seul fichier par classe. Les notes sont saisies sur l'échelle réelle de l'épreuve. ÉLIMU convertit automatiquement sur /20 et calcule la moyenne pondérée.
Format Classique — Niveau 3 (CM1, CM2)
Deux formats acceptés :
Format A (recommandé)
Col A : Nom   Col B : Prénom   Col C : Note (0-20)
Format B
Col A : Nom Prénom (fusionnés)   Col B : Note (0-20)
💡 Les virgules sont acceptées comme séparateur décimal (ex: 12,5)

Génère un bulletin PDF pour chaque élève de la classe en une seule opération. Les fichiers sont sauvegardés dans le dossier de votre choix.

💡 Comment ça fonctionne
1. Sélectionnez la classe et le trimestre à imprimer
2. Cliquez sur "Générer tous les bulletins"
3. Choisissez le dossier de destination
4. Les bulletins sont générés automatiquement — un PDF par élève
Chaque fichier est nommé automatiquement :
bulletin_NOM_Prénom_Trimestre_1.pdf
⚙️ La mise en page applique votre configuration depuis Paramètres → Bulletin
