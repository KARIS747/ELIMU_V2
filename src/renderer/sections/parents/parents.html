💡 Comment ça fonctionne
1. Configurez votre URL et votre Clé API (disponibles sur votre tableau de bord en ligne).
2. Lancez la synchronisation pour envoyer les élèves, parents et notes vers le portail.
3. Les parents peuvent alors se connecter avec leur numéro de téléphone et le mot de passe généré.
4. La restauration Cloud permet de récupérer toutes vos données en cas de changement de PC.
Conseil de sécurité

Pensez à synchroniser après chaque période de saisie de notes pour informer les parents en temps réel.
