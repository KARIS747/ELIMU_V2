CHAPITRE 1 : BIENVENUE DANS L'AVENTURE ELIMU
===============================================================================

Félicitations ! Vous venez d'acquérir Elimu (qui signifie Education en Swahili). 

Pourquoi Elimu est différent ?
La plupart des logiciels scolaires sont compliqués et tristes. Elimu a été créé pour être visuel et fluide, comme une interface de jeu vidéo (FIFA Style). 

- Les Etoiles : Elles indiquent le niveau de l'élève en un coup d'oeil. Plus l'élève a de bonnes notes, plus il gagne d'étoiles.
- Le Bilinguisme : Tout le logiciel et ses documents (bulletins, reçus) sont en Français et en Anglais. C'est idéal pour les établissements bilingues.

CHAPITRE 2 : INSTALLATION ET ACTIVATION
===============================================================================

2.1 Comment installer Elimu ?
1. Double-cliquez sur le fichier d'installation que vous avez reçu (ex: Elimu-Setup.exe).
2. Si une fenêtre bleue de Windows apparaît, cliquez sur "Informations complémentaires" puis sur "Exécuter quand même".
3. Cliquez sur "Suivant" à chaque étape jusqu'à la fin. Une icône avec un chapeau de diplômé apparaîtra sur votre bureau.

2.2 Activer votre licence
Au premier lancement, le logiciel vous demande une clé pour fonctionner.
1. Une fenêtre s'ouvre avec un code appelé HWID (Identifiant Machine). 
2. Cliquez sur le bouton "Copier l'identifiant". Le logiciel va copier ce code tout seul.
3. Ouvrez votre messagerie (WhatsApp ou Email) pour envoyer ce code à KarisDev. 
4. ASTUCE TECHNIQUE : Pour mettre le code dans votre message, maintenez la touche Ctrl de votre clavier enfoncée et appuyez sur la touche V (Ctrl + V). Cela va "coller" le code.
5. Une fois que vous recevez votre Clé de Licence de la part de KarisDev, sélectionnez-la avec votre souris, copiez-la (maintenez Ctrl et appuyez sur C -> Ctrl + C).
6. Revenez dans Elimu, cliquez dans la case "Clé de Licence" et faites Ctrl + V pour coller la clé.
7. Cliquez sur "Activer". Votre logiciel est maintenant prêt !

CHAPITRE 3 : VOTRE ETABLISSEMENT SUR MESURE
===============================================================================

Avant de commencer à inscrire des élèves, il faut donner une identité à votre logiciel. Allez dans le menu de gauche et cliquez sur Configuration > Paramètres.

3.1 Identité de l'école
- Nom de l'école : Ecrivez le nom exact de votre établissement.
- Le Logo : Cliquez sur "Choisir un logo". Sélectionnez l'image de votre école sur votre ordinateur. 
C'est très important : un bulletin avec un logo officiel inspire confiance aux parents.
- En-têtes : Remplissez les noms de votre Délégation Régionale et Départementale. Cela apparaîtra en haut de vos bulletins.

3.2 Les Années Scolaires (PRIORITE ABSOLUE)
C'est la toute première chose à faire lors de la première ouverture du logiciel, avant d'inscrire le moindre élève ou de saisir une note.
1. Allez dans l'onglet Années Scolaires. 
2. Cliquez sur "Nouvelle année" (ex: 2025/2026). 
3. Une fois qu'elle apparaît dans la liste, cliquez impérativement sur le bouton "Activer" (elle doit devenir verte). 
Note : Sans année scolaire active, le logiciel ne peut pas classer vos données. C'est le socle indispensable de tout votre travail.

3.3 Changer d'Année Scolaire (Navigation)
Vous pouvez basculer d'une année à une autre à tout moment pour consulter les archives :
1. Allez dans Paramètres > Années Scolaires.
2. Cliquez sur le bouton "Activer" en face de l'année souhaitée.
Le logiciel va se fermer et REDEMARRER automatiquement pour charger proprement les données de cette période. C'est normal et nécessaire pour garantir la stabilité.

3.4 Gérer votre équipe (Utilisateurs)
Ne donnez jamais votre mot de passe administrateur à tout le monde. Créez des comptes pour vos collègues :
- Secrétaire : Peut inscrire les élèves, saisir les notes, gérer les accès parents et lancer la synchronisation avec le portail.
- Comptable : Peut encaisser l'argent et imprimer les reçus (mais ne peut pas changer les notes).
- Enseignant : Peut seulement saisir les notes de ses propres classes.

CHAPITRE 4 : L'ARCHITECTURE PEDAGOGIQUE (LE SOCLE)
===============================================================================

C'est l'étape la plus importante. Si la structure est bien faite, le logiciel travaillera tout seul pour vous.

4.1 Créer les Classes
Allez dans Académique > Classes. Cliquez sur "Nouvelle Classe".
Donnez-lui un nom (ex: 6ème A) et choisissez le niveau (Primaire ou Secondaire). Elimu chargera automatiquement les matières par défaut.

4.2 Configurer les Coefficients (Le "poids" des matières)
Sur la carte de votre classe, cliquez sur le bouton "Config.".
- Coefficients : Dans la colonne "Coeff", écrivez le poids de chaque matière. 
Exemple : Si les Mathématiques comptent deux fois plus que le Dessin, mettez Coeff 4 pour les Maths et Coeff 2 pour le Dessin.
Elimu utilisera ces chiffres pour calculer automatiquement les moyennes exactes sans que vous n'ayez besoin d'une calculatrice.

4.3 Organiser les Groupes de matières
Vous pouvez créer des groupes pour que le bulletin soit bien rangé.
Exemple : Créez un groupe "SCIENCES" et mettez-y les Maths, la Physique et la SVT.
Sur le bulletin final, ces matières seront regroupées avec une moyenne pour le groupe. C'est beaucoup plus lisible pour les parents.

CHAPITRE 5 : GESTION DES ELEVES
===============================================================================

5.1 Inscription individuelle
Pour inscrire un élève un par un, cliquez sur "Ajouter un élève". Remplissez son nom, son prénom et surtout le téléphone du parent. Ce numéro est crucial pour le portail web.

5.2 L'Importation Excel (Le secret pour gagner des heures)
Si vous avez une liste de 100 élèves :
1. Allez dans la classe et cliquez sur le bouton "Liste" (icône de fichier).
2. Cliquez sur "Générer le modèle Excel". Le logiciel crée un fichier vide sur votre ordinateur.
3. Ouvrez votre ancienne liste, sélectionnez les noms, copiez-les (Ctrl + C) et collez-les dans le modèle d'Elimu (Ctrl + V).
4. Enregistrez et faites glisser ce fichier dans la zone bleue d'Elimu.
C'est magique ! Tous vos élèves apparaissent instantanément dans la classe.

CHAPITRE 6 : LE PASSAGE EN CLASSE SUPERIEURE (MIGRATION)
===============================================================================

A la fin de l'année, Elimu vous aide à "promouvoir" vos élèves vers leurs nouvelles classes pour l'année suivante.

6.1 Utiliser le Préparateur de Nouvelle Année
1. Allez dans Paramètres > Années Scolaires.
2. Cliquez sur le bouton "Préparer la nouvelle année".
3. Choisissez l'année source (l'année qui se termine) et l'année de destination (la nouvelle année que vous venez de créer).

6.2 Configurer le passage des classes
Une liste de vos classes actuelles s'affiche. Pour chaque classe :
- Choisissez la classe de destination (ex: la 6ème A passe en 5ème A).
- Action spéciale "Archive" : Utilisez ceci pour les classes de fin de cycle (ex: la Terminale qui quitte l'école).

6.3 Gestion automatique du Redoublement
Cliquez sur le bouton "Redoublement" pour configurer les règles :
- Activez l'option et fixez une moyenne (ex: 10/20).
- Le logiciel vérifiera les notes de chaque élève : s'il a la moyenne, il passe en classe supérieure ; s'il ne l'a pas, il reste dans sa classe actuelle pour la nouvelle année.

6.4 Lancer la Migration
Cliquez sur "Lancer la migration". Elimu va copier tous les élèves vers la nouvelle année scolaire en un clic. Vous n'avez pas besoin de les réinscrire !

CHAPITRE 7 : LE CYCLE DES NOTES ET BULLETINS
===============================================================================

7.1 Travailler intelligemment avec les Professeurs
Vous n'avez plus besoin de recopier les notes des professeurs.
1. Générez un Modèle de notes Excel pour chaque classe.
2. Envoyez ce fichier aux professeurs (par clé USB ou WhatsApp).
3. Le professeur remplit les notes sur son propre ordinateur.
4. Quand il vous rend le fichier, glissez-le simplement dans Elimu. 
Les moyennes de toute la classe sont mises à jour instantanément.

7.2 Générer les Bulletins de Notes
Une fois toutes les notes saisies, allez dans Import/Export > Bulletins par classe.
1. Sélectionnez le trimestre (T1, T2 ou T3).
2. Choisissez votre style préféré : 
    - OFFICIEL : Classique et sobre.
    - MODERNE : Très visuel, avec des graphiques de progression.
    - MINIMAL : Epure, pour économiser l'encre.
3. Cliquez sur "Générer tous les bulletins". 
Le logiciel fabrique un document PDF unique. Si vous avez 50 élèves, vous aurez un fichier de 50 pages. Cliquez sur "Imprimer" et allez prendre un café pendant que l'imprimante travaille !

CHAPITRE 9 : LA COMPTABILITE SCOLAIRE
===============================================================================

9.1 Les Frais et les Tranches
Allez dans Finance > Types de frais.
Si l'école coûte 150 000 FCFA, vous pouvez créer 3 tranches de 50 000 FCFA chacune avec des dates limites. Elimu vous alertera automatiquement quand un élève dépasse la date.

9.2 Enregistrer un paiement à la caisse
1. Cherchez l'élève, cliquez sur "Nouveau Paiement".
2. Cochez les tranches que le parent règle aujourd'hui.
3. Cliquez sur "Enregistrer".
4. Le logiciel vous propose d'imprimer le Reçu PDF. Faites-le toujours ! Le reçu est bilingue et comporte un numéro unique pour garantir une sécurité totale.

9.3 Suivre les Impayés
Qui n'a pas encore payé ? Cliquez sur l'onglet "Impayés". 
Vous avez la liste immédiate des élèves en retard. Vous pouvez exporter cette liste en PDF pour la donner aux surveillants afin qu'ils passent dans les classes pour les rappels.

CHAPITRE 10 : PORTAIL PARENTS ET SECURITE CLOUD
===============================================================================

10.1 Donner les accès aux parents
Les parents peuvent suivre les notes et les paiements depuis leur smartphone.
1. Allez dans la section Parents. Cliquez sur "Générer tous les mots de passe". 
2. Cliquez sur "Imprimer les fiches". Découpez-les et remettez-les aux parents. Elles contiennent le lien du site et leur code secret.
Note : Cette tâche peut désormais être effectuée par la secrétaire pour libérer le directeur.

10.2 La Synchronisation Turbo (Totale par Année)
A la fin de chaque trimestre, cliquez sur "Exporter vers le portail". 
Toutes les données de l'école sont envoyées sur internet de manière sécurisée. 
- Envoi Complet : Le logiciel envoie l'historique de toutes vos années scolaires. Cela garantit une sauvegarde totale de votre établissement sur le Cloud.
- Indexation : Chaque donnée reste classée par année pour que l'historique soit toujours disponible.

10.3 Le Cloud Recovery (Votre gilet de sauvetage)
C'est la fonction la plus rassurante d'Elimu. Si votre ordinateur tombe en panne, est volé ou si vous changez de machine :
1. Installez Elimu sur le nouveau PC.
2. Allez dans Synchronisation et cliquez sur "Restaurer depuis le cloud".
En quelques secondes, TOUTE votre école revient à la vie (y compris vos anciennes années scolaires) : élèves, notes, historique financier, logo... Rien n'est perdu !

CHAPITRE 11 : MAINTENANCE ET DEPANNAGE
===============================================================================

11.1 Raccourcis Magiques
Habituez-vous à utiliser Ctrl + C pour copier et Ctrl + V pour coller. C'est le secret pour travailler deux fois plus vite.

11.2 Que faire si le logiciel "bloque" (Freeze) ?
Bien qu'Elimu soit optimisé, il peut arriver que l'interface ne réponde plus aux clics ou que les champs de saisie soient bloqués.
- SOLUTION : Fermez totalement le logiciel et REDEMARREZ-LE. 
- Note : Elimu est conçu pour enregistrer vos données en temps réel. Un redémarrage ne vous fera rien perdre.

11.3 Changements de Session
Pour votre sécurité et la stabilité des données, Elimu REDEMARRE automatiquement lors de certaines opérations critiques :
- Changement d'utilisateur (Déconnexion).
- Changement d'année scolaire active.
- Restauration de données depuis le Cloud.

11.4 Journal d'activité
Vous pouvez vérifier qui a fait quoi. Si une note change mystérieusement, le journal vous dira quel utilisateur l'a modifiée et à quelle heure.
